# 文章管理台（Posts Admin）

一个内置在本地的可视化文章管理工具，用于**浏览文章列表、修改文章属性、快速创建新文章、编辑正文、上传图片**，全部改动直接写入 `src/content/posts/`，不经过任何外部服务。

- 零第三方依赖（只用 Node 内置模块 + 原生前端）
- 只监听 `127.0.0.1`，仅本机可访问
- 保存时**尽量不破坏原文件格式**：未被修改的字段、注释、字段顺序、换行符（LF/CRLF）都会原样保留

## 快速开始

```bash
pnpm admin
```

浏览器会自动打开 <http://127.0.0.1:4399/>。建议同时在另一个终端运行 `pnpm dev`，这样点「预览」可以直接看站点效果。

### 常用参数

```bash
pnpm admin -- --port 4500     # 换端口（默认 4399，或设环境变量 ADMIN_PORT）
pnpm admin -- --no-open       # 不自动打开浏览器
pnpm admin -- --host 0.0.0.0  # 监听所有网卡（谨慎使用）
```

## 界面说明

### 左侧：文章列表

| 功能 | 说明 |
| --- | --- |
| 搜索 | 匹配标题、描述、标签、分类、文件名；支持以空格分隔的多关键词 |
| 筛选 | 全部 / 已发布 / 草稿 / 置顶 |
| 排序 | 发布日期、修改时间、标题、字数 |
| 列表项 | 显示标题、日期、字数、标签，以及「草稿 / 置顶 / 🔒」标记 |
| 底部 | 统计信息、**回收站**、刷新 |

排序规则：置顶文章始终排在前面，其余按所选排序方式排列。

### 右侧：文章编辑

**属性区**直接对应 `src/content.config.ts` 里定义的 frontmatter 字段：

- 基础字段：标题、发布日期、更新日期、描述、封面图、标签、分类、草稿、置顶、允许评论、语言
- 高级字段（点「高级字段」展开）：别名路径、自定义固定链接、作者、来源链接、许可协议、排序优先级、加密文章 / 密码 / 密码提示

**正文区**支持三种视图：并排（Markdown + 实时预览）、仅编辑、仅预览。预览支持标题、列表、引用、代码块、表格、链接、图片、粗斜体、删除线。

**附件区**列出文章所在目录的图片与附件，可一键设为封面、插入到正文、复制路径或删除。

### 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl/⌘ + S` | 保存当前文章 |
| `Ctrl/⌘ + K` | 聚焦搜索框 |
| `Ctrl/⌘ + N` | 新建文章（焦点不在输入框时） |
| `Tab` | 在正文中插入缩进 |
| `Esc` | 关闭弹窗 |

## 功能细节

### 新建文章

点击「＋ 新建」，填写标题即可（slug 可留空，会按标题自动生成，中文标题会保留中文文件名，与现有文章一致）。

- **发布日期**默认今天，时区按 UTC+8 处理
- 可勾选「创建为草稿」
- 可勾选「使用文件夹」，生成 `article/article.md` 结构，便于附带图片
- 若同名文件已存在会直接拒绝（不会覆盖）

### 编辑与保存

- 保存前会带上文件的修改时间；若文件已被其它程序（编辑器、git 操作）改动过，会提示**冲突**，可选择强制覆盖，避免静默丢失改动
- 每次保存前，旧版本会自动备份到 `src/content/.trash/versions/<时间戳>/`
- 未保存就想切换文章时会有确认提示；关闭页面也会提醒

### 图片与附件

- 在附件区点「＋ 上传图片」，或直接把图片**拖入正文区**、**粘贴**（`Ctrl+V`）图片
- 上传后会在正文光标处插入 `![](./xxx.jpg)`
- 封面字段旁的「上传」按钮会把图片设为 `image`
- **重要**：如果文章原本是单文件（`name.md`），上传图片时工具会自动把它迁移成文件夹结构（`name/name.md` + `name/cover.jpg`），因为 `image: "./cover.jpg"` 这类相对引用需要与 md 文件同目录
- 图片体积上限 25MB

### 删除与恢复

「移入回收站」不会真正删除文件：

- 单文件文章 → 移入 `src/content/.trash/items/<时间戳>/`
- 文件夹文章 → 整个目录（含图片）一起移入
- 在「回收站」中可以**恢复**或**彻底删除**

`.trash/` 位于 `src/content/` 下但不在 `posts/` 中，因此不会被 Astro 的文章集合读到；它也已加入 `.gitignore`。

### 其它

- 「⋯」菜单：复制为新文章（生成草稿副本）、切换草稿状态、在资源管理器中显示、移入回收站
- 「预览」按钮会打开 `http://localhost:4321/posts/<slug>/`，需要先运行 `pnpm dev`
- 封面/图片预览通过 `/api/asset` 从文章目录实时读取

## 安全性

- 服务器只监听 `127.0.0.1`，不对外网暴露；没有任何鉴权，因此**不要**用 `--host 0.0.0.0` 把它暴露到公网
- 所有路径都会校验是否落在 `src/content/posts/` 内，`..` 之类的穿越请求返回 400
- 上传仅允许图片，且限制大小

## 实现与目录

```
scripts/admin/
├── server.js              # 零依赖 HTTP 服务器 + JSON API
├── lib/
│   ├── frontmatter.js     # frontmatter 解析/序列化（保真优先）
│   ├── fields.js          # 字段定义（与 content.config.ts 对齐）
│   └── store.js           # 文章读写、新建、回收站、图片
└── public/
    ├── index.html         # 管理台界面
    ├── style.css          # 样式（跟随站点色相）
    └── app.js             # 前端逻辑 + Markdown 预览
```

### API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/schema` | 字段定义 |
| GET | `/api/posts` | 文章列表 + 分类/标签/统计 |
| GET | `/api/post?id=` | 读取单篇（属性 + 正文 + 附件） |
| PUT | `/api/post?id=` | 保存（支持 `expectedMtime` / `force`） |
| POST | `/api/post` | 新建 |
| DELETE | `/api/post?id=` | 移入回收站 |
| POST | `/api/post/upload?id=` | 上传图片 |
| GET/DELETE | `/api/asset?path=` / `?id=&name=` | 读取 / 删除附件 |
| GET | `/api/trash` | 回收站列表 |
| POST | `/api/trash/restore` | 恢复 |
| POST | `/api/trash/purge` | 彻底删除 |
| POST | `/api/reveal` | 在系统文件管理器中显示 |

## 故障排查

| 问题 | 处理 |
| --- | --- |
| 端口被占用 | `pnpm admin -- --port 4500` |
| 页面显示“初始化失败” | 确认在项目根目录启动，且 `src/content/posts/` 存在 |
| 保存提示冲突 | 文章被外部改动，刷新后重试，或选择强制覆盖 |
| 图片不显示 | 确认 `image` 用 `./文件名` 的相对路径，且图片与 md 在同一目录 |
| 上传后文章变成文件夹 | 这是预期行为（见上文「图片与附件」） |

## 与旧脚本的关系

`pnpm new-post <文件名>` 仍然可用，只是仅创建空模板；需要可视化操作时用 `pnpm admin`。

## 自测

```bash
pnpm admin:test:fidelity   # 只读：确认读取->写回后文章文件逐字节不变
pnpm admin:test            # 端到端：自起服务器，跑一遍增删改查与回收站
```

`admin:test` 会临时创建一篇「管理台自测文章」并在结束时清掉，中途会临时修改并还原一篇真实文章（修改前的版本会备份在 `src/content/.trash/versions/`，可直接删除）。
